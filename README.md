# Source Code for www.chromium.org

Welcome to the Git repository containing the source content for [www.chromium.org](https://www.chromium.org).

The website is implemented by serving static content, mostly Markdown files, which are translated/build ahead of time into HTML using the [Eleventy](https://11ty.dev) static site generator (written in Node.js/JavaScript). The deployed website is hosted on [Firebase Cloud Hosting](https://firebase.google.com/products/hosting).

## Contributing

If you'd like to contribute to the site, please refer to the [CONTRIBUTING.md](docs/CONTRIBUTING.md) file for guidelines.
